# Infant Joseph — Cloud / DevOps Portfolio

Responsive React and Vite portfolio with project case studies, an experiments lab, experience and education pages, and a contact page.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

Project preview panels are labeled illustrative because no original project screenshots or repository links were provided. The photo areas are placeholders for a portrait.
